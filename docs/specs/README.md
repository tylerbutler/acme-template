# Feature specifications

Add reviewed specs as `NNNN-short-name.md`. Link the project brief and
the issue that requests the work.

Each spec states the goal, observable behavior, acceptance scenarios,
constraints and non-goals. Keep the first change small enough for one
issue and one PR.

Merge the spec and get the owner's build approval before implementation.
Do not treat a proposed spec or an agent's own assignment as approval.
There are no approved feature specs in this starter.
